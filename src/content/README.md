# Content Directory (`src/content/`)

All user-facing copy, metadata, links, and long-form Markdown live in this directory. Updating the site's text or adding projects/posts only requires editing files here.

## File Map

| File                         | Description                                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `site.yaml`                  | Site metadata, single-source `nav` entries (navbar, hero CTAs, footer), `embedAllowlist`, and `ui` chrome strings               |
| `profile.yaml`               | Owner name, localized title & location, `timezone`, hero tagline, current status, stats, `primaryCta`, and `about` markdown key |
| `skills.yaml`                | Categorized skill groups (`groups`) and full-bleed marquee items (`marquee`)                                                    |
| `experience.yaml`            | Work and study timeline (`period.end: null` renders as Present)                                                                 |
| `projects.yaml`              | Project tiles, status (`active`, `wip`, `archived`), cover image, links, embeds, and optional markdown `body`                   |
| `friends.yaml`               | Friend site cards (`items`) and this site's link-exchange info (`exchange`)                                                     |
| `contact.yaml`               | Primary email address and social links                                                                                          |
| `md/about.<lang>.md`         | Long-form About section content rendered inside the terminal window                                                             |
| `md/projects/<id>.<lang>.md` | Optional long-form description for each project                                                                                 |
| `blog/<slug>.<lang>.md`      | Blog posts with `title` and `date` YAML front matter                                                                            |
| `.generated/og.json`         | Open Graph link preview cache generated by `scripts/fetch-og.mjs` (committed, do not edit by hand)                              |

## Conventions

- **Localized values**: Write `{ en: "...", "zh-TW": "..." }` for translatable strings, or a plain string for language-neutral values (URLs, IDs, dates, technical tags).
- **Placeholders**: Keep complete sentences in YAML and use `{name}` / `{count}` placeholders for dynamic values.
- **Verification**: Run `pnpm test` and `pnpm check` after editing content.
