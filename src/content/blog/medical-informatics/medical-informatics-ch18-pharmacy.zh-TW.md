> **重要考點**
>
> - 最優先：==PRN 需要時、STAT 立即、DC 停用、Change 改變、Renew 重整／續開==。
> - **停用後列退藥單、核對數量交回藥局 → DC order**；「每日量只帶一天、需要才用」對應 PRN。
> - **雲端藥歷欄位**可含主診斷、藥名、用法用量；「藥物交互作用」是比對與判斷的結果，勿當成原始欄位。
> - 藥品耗用四分類的比例：**高耗 10%、一般 70%、低耗 10%、其他 10%**。
> - ADR 分級題要能對回固定敘述：**嚴重＝死亡／危及生命；中度＝延長住院且不舒服；輕度＝僅延長住院**。此列為本章考試分級記法。

# 1. 系統整合架構

資訊化不只是列印藥袋，更要讓病人、藥品、處方版本、實際交付及庫存可相互核對。本章的藥費占營業額 17–25% 屬背景引述，不當作當前所有醫院的統計。

# 2. 醫院門診藥局

## 2.1 處方資料及合法性確認

《藥品優良調劑作業準則》第 19 條的七項確認內容可記成：

1. **病人**：姓名、年齡、性別及病名。
2. **醫師與機構**：醫師姓名、簽章、機構名稱地址電話；管制藥品另有執照資訊。
3. **藥品**：名稱、劑型與單位含量。
4. **數量**：數量或重量。
5. **用法**：劑量與用藥指示。
6. **日期**：開方日期。
7. **連續處方**：調劑次數與間隔。

除內容外，還須確認處方的合法性、完整性與有效性。

## 2.2 四類用藥資訊檢核

| 檢核         | 目的                                   | 注意                                       |
| ------------ | -------------------------------------- | ------------------------------------------ |
| 健保給付限制 | 檢查診斷、報告或事前審查等條件         | 本章例子涉及特定藥品的檢驗值或診斷條件     |
| 重複用藥     | 找出同成分或同類藥重複，包含跨科與跨院 | 需考慮有效期間、實際服用及合理併用         |
| 交互作用     | 比對目前處方及其他用藥的風險           | 資料庫需更新，並依嚴重性及情境處理         |
| 雲端藥歷     | 輔助取得跨院用藥與相關醫療資訊         | 需確認資料時間與範圍，並向病人核對實際用藥 |

## 2.3 藥袋與處方箋不同

**處方箋**傳遞開方內容；**藥袋／容器標示**提供病人辨識及使用資訊。《藥師法》第 19 條要求包括病人姓名性別、藥名劑量數量用法、作用或適應症、警語或副作用、藥局及調劑者、調劑日期。本章另提藥袋可列藥品外觀、警語及其他用藥指示。

# 3. 住院單一劑量配送制度

## 3.1 基本流程

醫師開立藥囑 → 系統傳送／藥師審查 → 計算首日量與固定配送量 → 調配或包藥 → 按病房／病人分送 → 護理核對與給藥 → 記錄變更、停用、退藥及費用。

| 項目           | 重點                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| **首日量**     | 開方後到下一次固定配送銜接前所需的量；依開始時間及給藥時刻計算，不是固定一整天的量 |
| 固定交車與入帳 | 固定時間彙整、列印或傳至包藥機，調配與配送；不適用自動包藥的項目另處理             |
| 退藥           | 依停用時間及實際未使用數量核對、點收，處理庫存及費用；不能只依理論值直接視為已退回 |
| 重整           | 檢視持續藥囑，排除不必要重複；可定期批次或在開方時即時檢查                         |
| 管制藥品       | 依適用規定管理專用處方、使用紀錄、領退與結存，與一般藥品流程作必要區隔             |

## 3.2 常見藥囑類型

| 類型                   | 處理意義                                           |
| ---------------------- | -------------------------------------------------- |
| New order 新藥囑       | 建立新用藥，計算首日量及後續配送                   |
| PRN order 需要時使用   | 記錄需要條件及相關限制；配送量不等於實際每次給藥量 |
| Change order 更改      | 依新頻率及時間計算需補或需退的差額                 |
| DC order 停用          | 停止後續配送、核對剩藥，保留停止時間及原因         |
| Renew order 重整／續開 | 依制度確認持續用藥；未續開項目如何處理須明定       |
| STAT order 立即給藥    | 即時需求，明確記錄總量與執行                       |
| Multiple dose 多重劑量 | 如一瓶多次使用的藥，配送、計費與實際給藥分開管理   |
| 管制藥品藥囑           | 納入專用紀錄、保管、領用及結存核對                 |

# 4. 藥品庫存管理

## 4.1 四個存量名詞

| 名詞       | 本章定義／用途                 |
| ---------- | ------------------------------ |
| 安全存量   | 從訂購到驗收期間所需耗用量     |
| 最高存量   | 理想採購量＋安全存量           |
| 理想採購量 | 一個採購週期內的實際消耗量     |
| 採購週期   | 同一藥品兩次採購之間的間隔時間 |

## 4.2 分類與撥補

本章依口服、針劑、水藥及其他分組，再依耗用量及體積規劃：

| 類型               | 管理重點                             |
| ------------------ | ------------------------------------ |
| 高耗用量           | 較短撥補週期，避免缺貨               |
| 一般藥品           | 監控平均耗用及變化，定期補貨         |
| 低耗用／血清製劑   | 注意最小包裝、臨床重要性及過期風險   |
| 大型點滴等大體積品 | 降低一次持有量、較頻繁配送，節省空間 |

## 4.3 系統應提供的能力

- 依實際耗用、在庫及已訂未到量產生補貨建議，配合最小包裝與核准程序。
- 提醒效期與存量，協助處理即將到期或存量異常的藥品。

# 5. 藥物資訊服務與預防

## 5.1 藥物不良反應 ADR

| 本章考試分級 | 固定敘述對照                       |
| ------------ | ---------------------------------- |
| 嚴重         | 造成病人死亡或危及生命             |
| 中度         | 延長病人住院時間，且造成病人不舒服 |
| 輕度         | 僅延長病人住院時間                 |

本章將 ADR 分為**嚴重、中度、輕度**三個等級，並指出錯誤處方、缺乏病人或藥品資訊、不當藥品與劑量是重要問題。資訊系統可整合病人用藥、過敏、影像、檢驗與主診斷資料，支援可預防性 ADR 的偵測。

## 5.2 預警如何運作？

| 方式         | 本章重點                                               |
| ------------ | ------------------------------------------------------ |
| 直接預防警告 | 結合用藥、藥物濃度與個別病人條件，辨識可能不適當的處方 |
| 間接預防警告 | 追蹤檢驗、症狀及趨勢，找出可能已出現的不良反應徵兆     |

資料來源包含**處方、既有藥歷、過敏、主診斷、臨床表徵與檢驗值**。到達門檻後通知醫師、藥師評估，追蹤處理結果。

預警表以「藥物＋臨床表徵／檢驗」呈現警示設計。本章另列 **ACLS：Automatic Computerized Laboratory Signals（自動電腦化實驗室訊息）**，作為藥物不良反應的檢測支援工具。

## 5.3 電腦輔助劑量選擇

| 輸入／輸出 | 內容                                               |
| ---------- | -------------------------------------------------- |
| 病人參數   | 年齡、體重、腎功能相關檢驗及肝腎等特殊情況         |
| 藥物參數   | 廓清率、半衰期、有效與毒性濃度、生體可用率、頻率等 |
| 計算與建議 | 預估濃度、初次／負荷劑量與維持劑量等，視模型而定   |
| 後續確認   | 核對輸入、單位、模型適用性、採檢時點與治療反應     |

# 6. 社區藥局資訊系統

| 功能群         | 內容                                                     |
| -------------- | -------------------------------------------------------- |
| 處方管理       | 病人與醫師資料、一般／連續處方、調劑次數與期間           |
| 藥物資訊       | 藥名、規格、價格、過敏、交互作用、特殊族群與合法替代規則 |
| 費用及申報     | 藥費、部分負擔、收據明細、健保申報格式與送件             |
| 標示與指導     | 藥袋／標籤、用法及注意事項                               |
| 藥歷           | 留存調劑歷史與必要的安全紀錄                             |
| 進銷存         | 掃碼訂貨、供應商交換、批效期、庫存及帳務                 |
| 團隊／連鎖協作 | 查詢其他成員庫存及適當調度，配合權限管理                 |
