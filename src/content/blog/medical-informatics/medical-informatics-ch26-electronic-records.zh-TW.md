> **重要考點**
>
> - 期限先背：==製作後 24 小時完成電子簽章＝一天；一般病歷至少保存七年==。
> - **四多：目的、資料格式、關係人、照護型態**；「多重保障」「多重寫入方式」是常見錯項。
> - 跨院延續照護的重要途徑是**院間電子病歷交換**；電子化也可促進個人化健康管理與精準醫療。
> - **紙本具有獨佔性**，不便多人同時取用；電子病歷需配合授權及安全管理。
> - 法令先抓電子簽章法、醫師法、醫療法與電子病歷辦法；簽章期限、保存期限、管理紀錄期限分開。

# 1. 四種特質與六項目標

## 1.1 四種特質

| 特質         | 內容                                                   | 意義                               |
| ------------ | ------------------------------------------------------ | ---------------------------------- |
| 多重目的     | 照護、費用、教學、研究、法規及管理                     | 相同資料可依法支援不同用途         |
| 多重格式     | 文字、數字、圖片、聲音、影片、生理訊號及基因相關資料等 | 儲存、呈現與交換需處理不同型態     |
| 多重關係人   | 病人、醫師、護理、藥師、檢驗及機構等                   | 共同照護不代表每個人都能無限制閱覽 |
| 多重照護型態 | 急診、一般疾病、慢性病、預防及遠距照護                 | 支援跨時間、跨場域的延續照護       |

## 1.2 六項目標

1. **照護延續**：讓不同時間與照護者取得必要資料。
2. **決策支援**：以病人資料及知識協助判斷。
3. **教學與研究**：在合法範圍內搜尋、分析及學習。
4. **給付依據**：支持醫療服務、費用與申報資料。
5. **法律證據**：保留診療、處置、時間與責任的可追溯記錄。
6. **效率**：減少重複輸入、傳遞及查找負擔。

# 2. 演進的六種型態

| 型態             | 核心內容                             | 尚未解決的問題                       |
| ---------------- | ------------------------------------ | ------------------------------------ |
| 紙本病歷         | 人工記錄並以實體保存                 | 尋找、同時使用及統計不易             |
| 電子化病歷管理   | 用條碼、RFID、索引管理紙本位置與流向 | 管理工具電子化，內容仍可能主要是紙本 |
| 混合式病歷       | 紙本與電子資料並存                   | 需釐清完整記錄、版本及工作流程       |
| 多媒體電子病歷   | 整合文字、數值、影像、聲音及影片等   | 仍需共同辨識、語意與授權管理         |
| 跨院交換網       | 在合法授權下交換必要病歷             | 格式、代碼、病人匹配與治理須協調     |
| 個人終生健康資訊 | 跨機構整合長期健康資料               | 完整性、個人參與及資料來源仍需管理   |

## EMR 與 EHR 的範圍

| 名詞 | 主要範圍                                 |
| ---- | ---------------------------------------- |
| EMR  | 醫療機構的電子診療記錄與相關作業         |
| EHR  | 個人長期健康資訊，擴及不同機構與照護場域 |

# 3. 五項優勢

| 優勢             | 本章重點                                               |
| ---------------- | ------------------------------------------------------ |
| 彈性與多模態呈現 | 同一資料可用不同方式顯示，整合文字、數字、聲音、影像等 |
| 取得便利         | 可即時、同時或遠端查閱                                 |
| 正確與完整       | 系統可檢核欄位、範圍及相關資料，協助減少錯誤           |
| 管理與研究       | 便於查詢、統計、分析及決策支援                         |
| 安全管理         | 可利用權限、使用紀錄及相關機制保護資料                 |

# 4. 互通標準、架構與發展方向

## 4.1 一致的國際醫療資訊標準格式

共同資料格式讓交換雙方了解傳輸內容與意義。本章列舉的交換單張包括**急診病摘、慢性處方箋、出院護理、門診病歷、檢驗報告**；並提及評估導入 **FHIR**，開發交換單張申請與審查流程。

## 4.2 集中、分散與可攜資料

| 方式       | 資料管理觀念                                                    |
| ---------- | --------------------------------------------------------------- |
| 資料庫導向 | 資料集中在醫院伺服器，使用者以主從或網頁方式連線存取            |
| 文件式導向 | 以 XML 檔案作為電子病歷載具，支援資料交換、可攜式病歷與分散管理 |

# 5. 電子簽章、數位簽章與加密

| 名詞           | 重點                                       | 不要混淆                                             |
| -------------- | ------------------------------------------ | ---------------------------------------------------- |
| 電子文件       | 以電子等方式製成，供處理使用的記錄         | 不限文字檔，也可包含影像及聲音                       |
| 電子簽章       | 與文件關聯，用來辨識簽署者與確認文件真偽   | 不能把任何貼上的簽名圖片都直接視為已滿足全部法定要求 |
| 數位簽章       | 電子簽章的一種，運用私密／公開金鑰及憑證等 | 簽章產生與驗證不同於保密資料的加解密用途             |
| 加密           | 使未獲授權者難以理解資料內容               | 保密不等於已完成合法簽章或授權                       |
| 憑證／憑證機構 | 連結身分、資格與簽章驗證資料／簽發憑證     | 仍需憑證及金鑰的有效管理                             |

本章所列《電子簽章法》第 4 條重點：

- 經相對人同意，可用電子文件作為表示方法。
- 應以書面為之者，內容能完整呈現且可供日後查驗，經相對人同意可用電子文件。
- 法令或行政公告可另定排除適用、技術與程序等規定。

# 6. 醫師法與醫療法：病歷基本義務

## 6.1 醫師法第 12–14 條

| 條號     | 重點                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| 第 12 條 | 製作病歷，簽名／蓋章及日期；基本身分資料以外，至少含就診日期、主訴、檢查及結果、診斷、治療／處置／用藥與其他應記事項 |
| 第 13 條 | 處方需有醫師及病人、藥名、劑量、數量、用法與日期等資訊，並簽名／蓋章                                                 |
| 第 14 條 | 交付藥劑時的容器／包裝標示，涵蓋病人、藥品、用法、安全資訊、機構及調劑者等                                           |

## 6.2 醫療法第 66–72 條

| 條號     | 記憶重點                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 第 66 條 | 醫院診所交付藥劑時的標示義務                                                     |
| 第 67 條 | 病歷應清晰、詳實、完整；含醫師病歷、檢查檢驗報告及其他醫事人員記錄               |
| 第 68 條 | 親自記錄並簽名／蓋章與日期；增刪需可辨識；急迫口頭醫囑須於 24 小時內完成書面記錄 |
| 第 69 條 | 符合電子病歷規範時得免另製紙本，授權訂定相關辦法                                 |
| 第 70 條 | 保存、停業承接及安全銷毀；一般至少 7 年、未成年至成年後 7 年、人體試驗永久       |
| 第 71 條 | 病人可請求複製本，必要時提供中文摘要，不得無故拖延／拒絕，費用由病人負擔         |
| 第 72 條 | 因業務知悉或持有病人病情及健康資訊，不得無故洩漏                                 |

# 7. 電子病歷辦法：管理、製作與簽章

《醫療機構電子病歷製作及管理辦法》版本為 **2022-07-18 修正**。

## 7.1 六項管理機制（第 3 條）

| 機制         | 內容                                           |
| ------------ | ---------------------------------------------- |
| 標準作業     | 建置、維護及稽核的作業程序                     |
| 權限管控     | 製作、存取、增刪、查閱、複製與傳輸等權限       |
| 緊急應變     | 故障預防、通報、應變及復原                     |
| 系統安全     | 系統、正確時間、備援、備份與其他保護           |
| 傳輸加密     | 以適當標準加密機制保護網路傳輸                 |
| 安全事故處理 | 入侵、洩漏、毀損等事故的預防、通報、處置及修正 |

執行上述機制的管理紀錄==至少保存五年==。第 4 條的其他保護包含身分確認、個資隱碼、系統驗證確認、存取監控、入侵防範及異常使用處理。

## 7.2 委外、雲端與實施（第 6–10 條）

- **委外不免責**：醫療機構仍負法定責任；受託者資格、資安驗證及書面契約依規定辦理。同一法人、學校或機關所屬醫院等法定情形有契約例外。
- **契約內容**：範圍、權利義務、適用規範、資源授權、保密、內控稽核、終止及資料處理、主管機關取件、異常立即通知、再委託條件等。
- **雲端管理**：風險控管、服務不中斷、監督及退出移轉機制；資料原則儲存我國境內，特殊情形須經中央核准，服務者另須符合驗證要求。
- **實施備查**：開始日期與範圍、相關契約及驗證文件，自實施日起 **15 日內**報地方主管機關；變更範圍、受託者或停止時亦同。
- **評鑑與申報**：非有特殊理由，相關機關不得要求電子病歷列印／影印本；不是所有情況都絕對禁止列印。

## 7.3 製作及簽章（第 11–12 條）

1. 確認操作者**身分與權限相符**後才進行。
2. 增刪前後可明顯辨識，保留使用者與日期記錄。
3. 病歷製作後 **24 小時內完成電子簽章**，之後存檔及備份。
4. 因故不能及時簽章時，由機構依規定以醫事機構憑證代簽；除特殊情形外，醫事人員事後補簽。
5. 原則使用主管機關核發醫事人員憑證；機構另訂符合電子簽章法的合法方式者可依其方式辦理。

# 8. 保存、移轉、轉錄與交換

## 8.1 操作記錄與儲存媒體（第 13–16 條）

| 主題         | 要保留／處理的內容                                                   |
| ------------ | -------------------------------------------------------------------- |
| 操作稽核     | 病歷保存期間內，保留存取、增刪、查閱、複製等操作的人員、時間與內容   |
| 停業承接移轉 | 記錄原因、對象、方法、時間、地點與合法依據，交由承接者保存至少五年   |
| 媒體報廢汰換 | 完全移除或清除資料；仍可還原或無法清除時需實體破壞                   |
| 電子病歷銷毀 | 記錄人員、方法、時間與地點至少五年；委外亦同，派人全程確認並拍照存證 |

## 8.2 紙本轉錄（第 17 條）

**轉錄 → 核對與原件一致 → 醫事機構憑證簽章封存 → 報主管機關備查 → 依規定視同電子病歷。**

## 8.3 交換及同意（第 18–21 條）

跨機構交換原則使用依法設置／認可的交換平台，特定所屬醫院共用系統有例外；交換格式、簽章及時戳另依公告。

| 同意情形                         | 本章條文重點                       |
| -------------------------------- | ---------------------------------- |
| 一般病人                         | 先取得病人同意                     |
| 情況緊急且不能及時取得           | 法定例外，不是所有情況都可省略同意 |
| 胎兒                             | 母親同意                           |
| 限制行為能力／受輔助宣告         | 本人及法定代理人／輔助人同意       |
| 無行為能力／受監護宣告           | 法定代理人／監護人同意             |
| 無意思能力成年人且未能依前述處理 | 依規定取得親屬或關係人同意         |

# 9. 通訊診療：2022 年修正草案

本節為 **2022-11-24《通訊診察治療辦法》修正草案**的重點。

## 9.1 十類特殊情形（草案第 3 條）

1. 急性後期照護。
2. 慢性病長期用藥照護。
3. 長期照顧服務。
4. 家庭醫師收治照護。
5. 居家醫療照護。
6. 疾病末期照護。
7. 行動不便照護。
8. 災害、傳染病或其他重大變故照護。
9. 國際醫療照護。
10. 其他主管機關指定情形。

## 9.2 急迫情形與八項服務（草案第 13–14 條）

急迫情形包括**生命處於危急狀態**，或其他緊急情況有立即接受醫療處置的需要。

八項醫療服務：**詢問病情／諮詢、診察／診斷／醫囑、開立檢查檢驗單、會診、開立處方、原處方調整或指導、衛生教育／預防保健、其他指定項目**。

## 9.3 處方條件（草案第 15 條）

| 適用對象                                     | 草案中的開方條件                                               |
| -------------------------------------------- | -------------------------------------------------------------- |
| 第 3 條第 1–6 款                             | 病情穩定的複診病人                                             |
| 山地離島偏僻地區、第 3 條第 7–9 款、急迫情形 | 初診及複診病人                                                 |
| 管制藥品                                     | 原則不得包括；本章列山地離島偏僻地區、疾病末期及急迫情形為例外 |

## 9.4 實施計畫、資安與記錄（草案第 17–20 條）

- **實施計畫**：特殊情形通訊診療須擬計畫，報地方主管機關核准；內容包括人員、醫療項目、對象、期間、合作機構、同意書範本、個資與檔案安全措施及其他指定事項。
- **資訊系統**：涉及病歷傳輸、交換、儲存或開單時，需有身分驗證、傳輸加密並符合電子病歷辦法；委託建置管理須符合資安驗證與書面契約要求。
- **知情同意**：先取得對象同意；急迫情形有例外。
- **診療與病歷**：確認病人身分，原則由醫師在醫療機構內實施並確保隱私；病歷註明以通訊方式診療，其他醫事人員執行醫囑也須記錄。

# 10. 台灣推動背景與 EHR 願景

本章記述 2009 年加速電子病歷、2011 年互通補助等計畫，以及 2020 年願景和 2022 年超過 400 家醫院介接等背景，應連同年份閱讀，不當作最新統計。

可從四項方向理解 EHR 願景：

1. 整合個人終生健康資料。
2. 具有合法存取及資料管理機制。
3. 連結醫學知識與臨床決策支援。
4. 支援急重症、慢性病、長照、居家與預防等全人照護。

# 11. 考前期限表

| 期限            | 對象／起算                                       | 不要混淆                             |
| --------------- | ------------------------------------------------ | ------------------------------------ |
| 24 小時         | 電子病歷製作後完成電子簽章                       | 與醫療法急迫口頭醫囑補書面是不同規範 |
| 15 日           | 電子病歷實施日起報地方主管機關備查               | 不是簽章時限                         |
| 72 小時         | 知悉影響營運或權益的安全事故起，通報地方主管機關 | 與通知當事人義務分開理解             |
| 至少 5 年       | 特定管理、移轉或銷毀等紀錄                       | 不代表所有病歷只留五年               |
| 至少 7 年       | 一般病歷                                         | 未成年及人體試驗另有規定             |
| 成年後至少 7 年 | 未成年者病歷                                     | 不是只從就診日起七年                 |
| 永久            | 人體試驗病歷                                     | 不套用一般七年                       |
