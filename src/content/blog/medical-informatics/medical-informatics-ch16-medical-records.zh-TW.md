> [!IMPORTANT]
> **重要考點**
>
> - **SOAP＝Subjective、Objective、Assessment、Plan**；POMR＝**Problem-Oriented Medical Record**。
> - 病歷五功能：==照護指引、醫療團隊溝通、法律證據、教學研究、保險給付憑據==。
> - 「團隊診療溝通」不要直接換成「病人與家屬溝通」；擴及生活型態、健康狀況的是 **Health record**。
> - **CM 看診斷，PCS 看處置；CM 3～7 字元、PCS 固定 7 字元**。
> - 送回病歷、補齊紀錄、完成簽章是不同工作與期限；**量審看齊不齊，質審看內容是否合理一致**。

# 1. 病歷的內涵與功能

## 1.1 狹義與廣義

| 層次                 | 內容                                                       |
| -------------------- | ---------------------------------------------------------- |
| 狹義：醫師製作的病歷 | 基本資料、日期、主訴、檢查與結果、診斷、治療、處置、用藥等 |
| 廣義：醫療機構病歷   | 醫師紀錄、各項檢查／檢驗報告，以及其他醫事人員執業紀錄     |
| 健康資訊             | 再擴展至預防、健康促進、健康狀態及相關生活資訊             |

《醫師法》第 12 條要求製作病歷並註明執行及簽章資訊；《醫療法》第 67 條要求病歷清楚、詳實、完整，且包括不同醫事專業的紀錄。

## 1.2 五項功能

1. **照護指引**：保留診斷、處置的理由及病程，使照護連續。
2. **診療溝通**：醫師、護理及其他專業共享病人狀況，協調照護。
3. **法律證據**：協助釐清事實與處理爭議。
4. **教學研究**：支援研究、成效與成本分析、高風險辨識及登錄。
5. **保險給付憑據**：提供服務真實性及必要性的記錄依據；只有費用或醫令而缺乏記錄，可能影響審查。

## 1.3 傳統與現代管理比較

| 傳統紙本管理                         | 現代健康資訊管理                         |
| ------------------------------------ | ---------------------------------------- |
| 格式設計、保管、排序、檔案及動態追蹤 | 資訊收集、整合、分析及管理               |
| 病歷量與質的審查、未完成追蹤         | 資料與資訊品質管理                       |
| 借閱、資料釋出及保密                 | 權限、資料釋出、資訊安全與隱私           |
| 疾病分類及統計                       | 編碼、資料倉儲、互通標準、研究與決策支援 |

# 2. 病歷記錄系統

## 2.1 SOAP 與各類紀錄

| SOAP          | 內容     | 理解例子                   |
| ------------- | -------- | -------------------------- |
| S：Subjective | 主觀資料 | 病人主訴與陳述的症狀       |
| O：Objective  | 客觀資料 | 診察、生命徵象及檢查結果   |
| A：Assessment | 評估     | 對問題與診斷的判斷         |
| P：Plan       | 計畫     | 檢查、處置、治療與追蹤安排 |

| 紀錄類型               | 主要內容                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 門、急診紀錄           | 就診目的、主訴、現病史、過去史、診察、診斷、用藥、檢查、處置與衛教                 |
| 入院紀錄               | 入院目的、病史、理學檢查、既有結果、入院診斷及診療計畫                             |
| 病程紀錄               | 病情變化、問題評估、治療進展與反應、後續計畫                                       |
| 住院醫囑及其他專業紀錄 | 醫囑、麻醉、護理評估、照護、轉科及衛教等                                           |
| 手術紀錄               | 日期、前後診斷、名稱、部位、方式、發現、過程、術者、器材／檢體、出血輸血及併發症等 |
| 出院摘要               | 入出院日期與診斷、病史及住院病程、重要發現、出院狀態、用藥、指示及衛教             |
| 檢查／檢驗報告         | 生化、微生物、血液、尿液、內視鏡、超音波、影像、核醫、病理等結果                   |

病歷首頁可呈現藥物過敏、DNR 等重要註記。

# 3. 疾病分類與統計系統

## 3.1 分類目的

將診斷及處置轉成標準代碼，以支援**查詢研究、保險申報、院內統計、管理決策、跨院及跨國比較**。標準代碼有助比較，但仍須考量版本、編碼品質、族群與統計口徑。

## 3.2 ICD-10-CM 與 ICD-10-PCS

| 面向         | ICD-10-CM                                  | ICD-10-PCS             |
| ------------ | ------------------------------------------ | ---------------------- |
| 主要對象     | 診斷、症狀、健康狀態及就醫原因等           | 醫療處置               |
| 長度         | 3–7 個字元，依代碼要求                     | 固定 7 個字元          |
| 結構         | 前三碼為類目，後續增加特異性；部分須第七碼 | 每一碼表示一個分類軸   |
| 小數點       | 第三碼後通常顯示小數點；點不算字元         | 不使用小數點           |
| 與支付碼關係 | 不是健保收費碼                             | 也不等於健保手術收費碼 |

**PCS 內外科章節七軸**：章節 Section → 身體系統 Body system → 根本處置 Root operation → 身體部位 Body part → 途徑 Approach → 裝置 Device → 附加特性 Qualifier。其他章節各位置的意義可能不同。

> [!WARNING]
> **U 字母題要先辨識問法**
>
> 題目可能問「第 1 碼不包含哪個字母」，也可能問「特殊目的／臨時分配碼」。兩種問法涉及不同版本脈絡，不能把「U 不使用」當成所有題目的固定口訣。

## 3.3 編碼流程與檢核

門、急診常由醫師選擇診斷並帶入代碼；住院則須整合整次住院資訊，不能只照入院時初步診斷編碼。常見檢核包括：主診斷可用性、年齡及性別條件、處置與相關診斷的合理性、代碼有效期及完整性。

# 4. 病歷審查與未完成管理

## 4.1 量與質的審查

| 面向     | 量的審查 Quantitative                                                | 質的審查 Qualitative                                                                 |
| -------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 核心問題 | **該有的紀錄是否齊全？**                                             | **內容是否正確、一致、清楚且合理？**                                                 |
| 檢查例子 | 入院紀錄、病程、手術紀錄、出院摘要、必要報告是否完成；是否簽章／複簽 | 診斷是否有依據、過程是否詳述、同意程序是否完整、不同紀錄是否矛盾、時間與縮寫是否恰當 |
| 性質     | 基本完整性與缺件檢查                                                 | 內容品質與臨床合理性檢查                                                             |
| 系統支援 | 必填檢核、缺件列表、提醒與追蹤                                       | 抽樣、分派、評分、連結原文、回饋及統計                                               |

「欄位有填」只能通過部分量的檢核，不代表內容真實、正確或臨床品質已合格。若有矛盾須向記錄者釐清，不應由系統自行猜測替換。

## 4.2 未完成病歷管理

1. 依院內規定收回或確認出院病歷。
2. 審查缺件、內容與簽章狀態，指派責任人。
3. 設定完成期限，透過系統、郵件或簡訊提醒。
4. 記錄補正及複核結果；完成後解除未完成狀態。
5. 統計逾期、未完成類型及改善情形。

本章列出出院後 24 小時或三天歸還、三天或七天補齊等做法，屬院內流程例子，不應一律當成法定期限。「從未完成清單刪除」意為解除追蹤狀態，不是刪除病歷或處理歷程。

# 5. 電子簽章管理

本章說明：電子病歷製作者透過醫事憑證（醫事人員卡）簽章；病歷製作後 **24 小時內**完成電子簽章。系統須管理簽章時效，並可透過電子郵件、簡訊提醒；離職前也須查核未簽章文件。

# 6. 閱覽、複製與借閱

| 功能     | 目的                                                 | 必要管控                               |
| -------- | ---------------------------------------------------- | -------------------------------------- |
| 閱覽查詢 | 整合門診、急診、住院及報告，依類別／日期／關鍵字查找 | 依角色與照護需要授權，保存存取紀錄     |
| 病歷複製 | 依合法申請提供特定期間、類型的副本                   | 核對身分、代理權、範圍、交付與釋出紀錄 |
| 紙本借閱 | 管理原件調出、位置、借閱期限及歸還                   | 申請核准、追蹤、逾期提醒               |
| 電子借閱 | 對非日常照護等需求開放限定的查閱權                   | 審核目的、範圍、期限，期限後撤銷權限   |

本章列《醫療法》第 71 條：依病人要求提供病歷複製本，必要時提供中文病歷摘要，不得無故拖延或拒絕；費用由病人負擔。非病人或法定代理人申請時，須有載明委託意旨與範圍的同意書。第 74 條另說明診療需要時，經相關同意向原院所商洽提供病歷、摘要及報告。

# 7. 保存與隱私管理

## 7.1 保存期限

| 類型         | 《醫療法》第 70 條最低保存要求 |
| ------------ | ------------------------------ |
| 一般病歷     | 至少七年                       |
| 未成年者病歷 | 至少保存至成年後七年           |
| 人體試驗病歷 | 永久保存                       |

本章指出電子病歷的保存等同紙本病歷的保存。

## 7.2 權限與稽核

- **最小權限**：只給工作所需的基本權限；特殊任務另行申請。
- **人事連動**：調職、離職時調整或撤除權限，定期複核。
- **使用紀錄**：保存人員、時間、病歷、操作及必要目的資訊。
- **異常處理**：不能只存 log，還要審視異常查閱、詢問原因及確認處置。

本章列《醫療法》第 72 條與《醫師法》第 23 條：對因業務知悉或持有的病情及健康資訊，**不得無故洩漏**。另介紹美國 1996 年 HIPAA 及臺灣個資法，以說明病歷隱私與資料安全。
