# 文章標記語法：螢光筆與提示框

除了一般的 Markdown（粗體、刪除線、表格、程式碼……），網站的 Markdown 另外支援兩種標記方式。

## 螢光筆 `==文字==`

| 寫法              | 效果     | 建議用途             |
| ----------------- | -------- | -------------------- |
| `==重點==`        | 黃色螢光 | 一般重點（預設）     |
| `=={green}重點==` | 綠色     | 好消息、推薦、成功   |
| `=={blue}重點==`  | 藍色     | 補充、名詞、中性資訊 |
| `=={red}重點==`   | 紅色     | 錯誤、地雷、千萬別做 |

規則：

- `==` 裡面的文字頭尾不能是空白，所以 `a == b` 不會被當成標記。
- 只有上面四個顏色；寫錯（例如 `=={pink}…==`）會原樣顯示。
- 要加粗請寫在外面：`**==粗體螢光==**`。`==**…**==` 不會生效。
- 程式碼（`` `==x==` ``）裡面不會被標記。
- 經歷頁的 `highlights` 這類 YAML 內的簡短 Markdown 也能用。

## 提示框 `> [!NOTE]`

和 GitHub 相同的寫法：在引用區塊第一行寫類型，下一行開始寫內容。

```markdown
> [!TIP]
> 安全審查不用等公布，照青培規格做海報就會過。
```

| 類型           | 標題（中／英）   | 顏色 | 建議用途         |
| -------------- | ---------------- | ---- | ---------------- |
| `[!NOTE]`      | 備註 / Note      | 藍   | 補充說明、前提   |
| `[!TIP]`       | 小提示 / Tip     | 綠   | 實用建議         |
| `[!IMPORTANT]` | 重要 / Important | 白   | 一定要記得的事   |
| `[!WARNING]`   | 注意 / Warning   | 黃   | 容易踩到的坑     |
| `[!CAUTION]`   | 警告 / Caution   | 紅   | 會造成損失的風險 |

標題文字在 `src/content/site.yaml` 的 `ui.markdown.alerts` 修改。沒有寫類型的引用（`> 一般引用`）維持原本的綠色直線＋斜體樣式。

## 圖片與圖說

```markdown
![公開展覽真的蠻受歡迎的](IMG_5499.jpeg)
```

- 圖片放在 `src/assets/blog/<文章 slug>/`，檔名大小寫不用完全一致（`.JPG`、`.jpg` 都可以）。
- `[ ]` 裡的文字會以小的淺灰字顯示在圖片下方當圖說，同時也是給螢幕閱讀器的替代文字，請不要留空。
- 圖片最高 480px、置中顯示。`.HEIC` 不支援，請先轉成 JPG。

> 為什麼原本 `==` 沒有效果？標準 Markdown 和 GitHub 的 GFM 都沒有螢光筆語法，`==` 是 Obsidian、Typora 等編輯器自己加的。這個網站現在用一小段自己的程式支援它。
